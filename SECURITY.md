# Security

TabSiesta inspects page state locally to decide whether a tab can sleep. Bugs
that expose page contents, lose protection state, or bypass safety checks deserve
careful investigation.

Do not post credentials, recovery phrases, drafts, or private browsing details
in public issues. Use synthetic reproductions and redact screenshots and logs.

For a sensitive vulnerability, check the maintainer's contact information at
https://github.com/ak5 and request a private reporting channel before sharing
details. If GitHub offers **Report a vulnerability** in this repository's Security
tab, use that private channel. Availability of private reporting is not assumed.

The project is a preview; there is no guaranteed response time or supported
historical release series. Fixes target the current development version.
